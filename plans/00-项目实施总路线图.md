## 当前下一步建议

当前项目已经具备 MVP 链路、真实平台简化数据层、Doubao provider 接入点、商品图片资产、Web Debug 和多 Agent 第一版能力。下一步建议进入真实 Doubao Key 联调、路演界面或移动端体验完善：

1. 在 `backend/.env` 填入 Doubao / Ark Key。
2. 确认 `BGE_M3_ENABLE_REAL=true` 和 `CHINESE_CLIP_ENABLE_REAL=true`。
3. 重建 Chroma 索引。
4. 用 Web Debug 验证真实 Doubao 文本回答和检索链路。
5. 图片向量走本地 Chinese-CLIP，不需要 TOS/公网图片 URL。
