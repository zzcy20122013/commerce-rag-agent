# 商品库扩充与图片资产准备计划 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在真实 Chinese-CLIP 接入前，先准备可用于图搜的商品图片资产和更丰富的商品 CSV，避免模型接入后只能检索占位图。

**Architecture:** 使用 `backend/app/data/catalog/images` 作为本地图片资产入口；使用 `backend/app/data/catalog/*.csv` 管理商品与图片绑定；通过 Plan 02 已实现的 catalog import 和 reindex 能力导入 SQLite 并重建 Chroma。

**Tech Stack:** CSV, local image files, FastAPI catalog import, SQLite, Chroma, bge-m3.

---

## 1. 范围

包含：

- 建立图片资产目录
- 准备图片命名规范
- 维护图片资产清单
- 扩充商品 CSV 到 40-100 条
- 商品绑定 `image_file`
- 导入商品并重建文本索引

不包含：

- Chinese-CLIP 模型安装
- 大规模图片爬取
- 云对象存储/CDN

## 2. 资产目录

```text
backend/app/data/catalog/images/
  tablets/
  headphones/
  shoes/
  backpacks/
```
