# 真实平台简化数据层计划 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将当前少量 seed 商品升级为可批量导入、可管理图片、可导入文档、可重建索引的真实电商平台简化数据层。

**Architecture:** FastAPI 后端继续保持单体服务。SQLite 负责商品主数据、SKU、属性、标签、图片、导入任务和索引任务；本地 `app/data` 目录模拟对象存储；Chroma 继续作为文本和图片向量库；导入服务负责把 CSV/JSON、图片、文档同步到 SQLite 与 Chroma。

**Tech Stack:** Python, FastAPI, SQLAlchemy, SQLite, Chroma, CSV/JSON, local file storage, pytest.

---

## 1. 范围

包含：

- 商品 CSV/JSON 导入模板
- 商品主数据字段扩展
- SKU、属性、标签、图片表设计
- 商品图片本地目录/URL 管理
- FAQ、营销文档、商品详情文档批量导入入口
- 一键重建 SQLite + Chroma 索引
- 导入报告和索引任务状态
- 样品库扩展入口，为 100-300 条商品做准备

不包含：

- 真实本地 embedding 模型部署
- 真实本地 embedding 模型部署
- 云对象存储/CDN
- 商家后台可视化管理系统
