## 当前下一步建议

当前项目已经具备 MVP 链路、真实平台简化数据层、Doubao 文本大模型接入、本地 bge-m3 / Chinese-CLIP 接入路径、商品图片资产、Web Debug 和多 Agent 第一版能力。

现在的主要偏差不是链路是否跑通，而是 Agent 体验还需要继续向“真人导购”靠拢：

1. 优先补强 Plan 05：统一导购说话规则、Prompt Registry、主推/备选/劝退表达、多轮约束继承和意图路由。
2. 同步启动 Plan 08 的小规模评测：先用 10-20 条典型问题验证意图识别、约束提取、检索召回、推荐合理性和多轮逻辑。
3. 待 Agent 回答质量稳定后，再进入 Plan 07 做正式项目路演界面。
4. Android 展示端 Plan 06 保留为后续真机体验验证，不放在当前最前面。
5. Plan 09 继续补 Docker、一键启动、日志和部署说明，作为项目交付前的工程化收尾。

## 下一步执行建议

现在进入：

> **Plan 05：Agent 能力补强** + **Plan 08：质量评测与反馈闭环小版**

当前不建议直接先做路演界面或 Android 真机展示，因为展示层会把 Agent 回答质量问题放大。更稳的顺序是：

1. 先把导购回答调得更自然、更有取舍。
2. 用小评测集固定核心场景，避免后面改一处崩一处。
3. 再做路演界面，把已经稳定的能力包装出来。
4. 最后做 Android 真机体验和工程化部署。
