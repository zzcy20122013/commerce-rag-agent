# 项目目录说明

本项目按“源码、调试端、移动端、文档、脚本”分层，根目录就是工程入口，不再额外套二级工程目录。

```text
agent/
├── README.md                         # 项目入口、启动方式和维护命令
├── .env.example                      # 根环境变量模板，复制到 backend/.env 使用
├── .gitignore                        # 排除密钥、数据库、模型权重、运行时索引和依赖目录
├── backend/                          # FastAPI Agent 服务
│   ├── app/
│   │   ├── agents/                   # IntentRouter、ShoppingGuide、FAQ、对比、图搜等 Agent
│   │   ├── api/                      # HTTP/SSE/上传/商品/反馈/会话接口
│   │   ├── data/                     # 示例商品、分类体系和本地运行数据入口
│   │   ├── embeddings/               # bge-m3 文本向量、Chinese-CLIP 图片向量适配层
│   │   ├── evaluation/               # 意图、检索、推荐、多轮记忆、图片召回评测
│   │   ├── llm/                      # 豆包调用、统一 prompt、生成兜底逻辑
│   │   ├── models/                   # SQLAlchemy 表、Pydantic 协议模型
│   │   ├── retrieval/                # Chroma 文本/图片索引、retriever、rerank
│   │   ├── scripts/                  # 导入商品、导入文档、重建索引、跑评测
│   │   └── services/                 # 商品、会话、反馈、文档、图片、分类服务
│   └── pyproject.toml                # Python 依赖定义
├── web-debug/                        # React 调试控制台，用来验证后端能力
│   ├── src/api/                      # SSE、上传、反馈、文档导入接口封装
│   ├── src/components/               # 消息、商品卡片、对比表等组件
│   └── src/pages/                    # DebugConsole 主页面
├── android/                          # Android Kotlin + Jetpack Compose 展示端
│   └── app/src/main/java/...         # 聊天、商品卡片、会话、上传、反馈页面
├── docs/                             # 项目文档总入口
│   ├── project/                      # 项目方案、后续注意事项、目录说明
│   ├── plans/                        # 00-09 阶段计划
│   ├── architecture/                 # 架构说明
│   ├── developer/                    # 开发修改指南
│   └── evaluation/                   # 评测说明和评测报告
└── scripts/                          # 常用 PowerShell 脚本
```

## 本地模型目录

`models/` 通常只存在于个人电脑，不属于正式 GitHub 仓库结构。它用于缓存 bge-m3、Chinese-CLIP 等本地模型权重；删除后源码还在，但真实本地 embedding 需要重新下载模型。

## Git 管理原则

- 提交：源码、配置模板、文档、示例商品 CSV、可展示的小体积图片资产。
- 不提交：`backend/.env`、SQLite 数据库、Chroma 索引、上传文件、运行日志、本地模型权重、依赖目录。
- 如果目录整理出问题，先回到整理前快照：`snapshot-before-project-cleanup-20260521`。
