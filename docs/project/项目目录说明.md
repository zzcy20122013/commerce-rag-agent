# 项目目录说明

本项目按“后端服务、Web 调试端、Android 展示端、文档、脚本、本地模型缓存、本地运行产物”分层。根目录就是工程入口，适合直接提交 GitHub、克隆运行和继续开发。

```text
agent/
├── README.md                         # 项目入口、启动方式和维护命令
├── .env.example                      # 唯一公开环境变量模板，复制到 backend/.env 使用
├── .gitignore                        # 排除密钥、数据库、模型权重、运行时索引和依赖目录
├── backend/                          # FastAPI Agent 服务
│   ├── app/
│   │   ├── agents/                   # IntentRouter、ShoppingGuide、PurchaseHelp、FAQ、对比、图搜、ResponseComposer 等模块
│   │   ├── api/                      # HTTP、SSE、上传、商品、购物车/提交订单、订单流转、反馈、会话和运行统计接口
│   │   ├── data/                     # 示例商品、分类体系和本地运行数据入口
│   │   ├── embeddings/               # bge-m3 文本向量、Chinese-CLIP 图片向量适配层
│   │   ├── evaluation/               # 意图、检索、导购、反馈闭环、多轮记忆和图片召回评测
│   │   ├── llm/                      # Doubao 调用、Prompt Registry、统一生成和 fallback 逻辑
│   │   ├── models/                   # SQLAlchemy 表、Pydantic 协议模型
│   │   ├── retrieval/                # Chroma 文本/图片索引、retriever、rerank
│   │   ├── scripts/                  # 导入商品、导入文档、重建索引、跑评测
│   │   └── services/                 # 商品、会话、购物车、订单、反馈、文档、图片、分类、错误处理和运行统计服务
│   └── pyproject.toml                # Python 依赖定义
├── web-debug/                        # React 调试控制台，用来验证后端能力
│   ├── src/api/                      # SSE、上传、反馈、文档导入接口封装
│   ├── src/components/               # 消息、商品卡片、对比表等组件
│   └── src/pages/                    # DebugConsole 主页面
├── android/                          # Android Kotlin + Jetpack Compose 展示端
│   └── app/src/main/java/...         # 聊天、商品卡片、推荐依据、语音输入、购物车/订单、会话、上传、反馈页面和本地 Mock fallback
├── docs/                             # 项目文档总入口
│   ├── project/                      # 项目方案、后续注意事项、目录说明
│   ├── plans/                        # 00-09 阶段计划
│   ├── architecture/                 # 架构说明
│   ├── developer/                    # 开发修改指南
│   └── evaluation/                   # 评测说明、评测报告和反馈闭环报告
├── scripts/                          # 常用 PowerShell 脚本
├── models/                           # 本地模型缓存，不提交 GitHub
└── outputs/                          # 本地评测、导出和临时运行产物，未提交 GitHub
```

如果根目录临时出现 `app/data/`，通常是从仓库根目录直接启动后端时生成的本地运行数据；正式后端运行数据应位于 `backend/app/data/`。

## 本地模型目录

`models/` 通常只存在于个人电脑，不属于正式 GitHub 仓库内容。它用于缓存 bge-m3、Chinese-CLIP 等本地模型权重；删除后源代码仍然保留，但真实本地 embedding 需要重新下载模型，并重新构建文本索引和图片索引。

## Git 管理原则

- 提交：源代码、配置模板、文档、示例商品 CSV、可展示的小体积图片资产。
- 不提交：`backend/.env`、SQLite 数据库、Chroma 索引、上传文件、运行日志、本地模型权重、依赖目录。
- 不提交本地临时评测辅助文件，除非已经整理进正式 `backend/app/evaluation` 或 `docs/evaluation`。
- 如果目录整理出现问题，先回到整理前快照：`snapshot-before-project-cleanup-20260521`。
