# 开发修改指南

这份文档回答一个问题：想改某个功能，应该先看哪里。

## Agent 和回答风格

- 导购说话规则：`backend/app/llm/prompt_registry.py`
- 可复用 prompt 片段：`backend/app/llm/prompt_blocks.py`
- LLM 调用与兜底生成：`backend/app/llm/generation.py`
- 豆包 OpenAI 兼容调用：`backend/app/llm/openai_compatible_client.py`
- 统一用户可见回复：`backend/app/agents/response_composer.py`
- 闲聊回复：`backend/app/agents/chitchat.py`

如果觉得回答太机械，优先看 `ResponseComposer` 和 `prompt_blocks.py` 中的 `RESPONSE_COMPOSER_TASK`；如果只有推荐场景有问题，再看 `SHOPPING_STYLE_RULES`。如果模型没调起来或超时，优先看 LLM client 和 `backend/.env`。

当前回答生成原则：

1. 业务 Agent 负责事实、检索、排序、订单状态和商品卡片。
2. ResponseComposer 负责把事实改写成真人导购口吻。
3. LLM 失败时保留各模块 fallback，保证系统不会空白。
4. 不允许 LLM 编造价格、库存、活动和不存在的商品。

## 意图路由和 Agent 流程

- 意图识别：`backend/app/agents/intent_router.py`
- LangGraph 主流程：`backend/app/agents/graph.py`
- 导购推荐：`backend/app/agents/shopping_guide.py`
- 商品知识问答：`backend/app/agents/product_knowledge.py`
- 商品对比：`backend/app/agents/compare.py`
- 决策辅助：`backend/app/agents/decision_guide.py`
- 多模态图搜：`backend/app/agents/multimodal.py`
- FAQ/售后：`backend/app/agents/faq.py`
- 购物车和购买辅助：`backend/app/agents/purchase.py`
- 闲聊兜底：`backend/app/agents/chitchat.py`
- 统一回复生成：`backend/app/agents/response_composer.py`

新增 Agent 时，通常要同时改 `state.py`、`intent_router.py`、`graph.py` 和对应 API 返回协议。
如果只是想统一说话风格，不要新增业务 Agent，优先改 ResponseComposer。

购物车这类有明确执行结果的回答，要优先保证商品、数量和操作事实准确。`purchase.py` 返回的加购、查看、删除、改数量结果不要被 ResponseComposer 改写出新的商品或数量。

## 商品检索和排序

- SQLite 商品查询：`backend/app/services/product_service.py`
- 分类和同义词：`backend/app/services/taxonomy.py`
- 分类配置：`backend/app/data/taxonomy.json`
- 文本检索入口：`backend/app/retrieval/retrievers.py`
- Chroma 文本索引：`backend/app/retrieval/text_index.py`
- Chroma 图片索引：`backend/app/retrieval/image_index.py`
- Rerank 规则：`backend/app/retrieval/reranker.py`

如果出现“用户问电脑却推荐耳机”这类问题，先看意图和约束提取，再看 taxonomy，最后看 retriever/rerank。

## 数据导入和索引

- JSON 数据集导入：`backend/app/scripts/import_json_dataset.py`
- CSV 商品导入：`backend/app/scripts/import_catalog.py`
- 非结构化文档导入：`backend/app/scripts/ingest_docs.py`
- 文本索引重建：`backend/app/scripts/ingest_text.py`
- 图片索引重建：`backend/app/scripts/ingest_images.py`
- 一键重建全部索引：`backend/app/scripts/rebuild_indexes.py`

常用命令：

```powershell
.\scripts\rebuild_indexes.cmd
```

## 接口和商品卡片协议

- SSE 聊天接口：`backend/app/api/chat.py`
- 商品接口：`backend/app/api/products.py`
- 图片上传接口：`backend/app/api/upload.py`
- 文档上传接口：`backend/app/api/docs.py`
- 反馈接口：`backend/app/api/feedback.py`
- 会话接口：`backend/app/api/sessions.py`
- 购物车接口：`backend/app/api/cart.py`
- 后端协议模型：`backend/app/models/schemas.py`
- 后端表结构：`backend/app/models/tables.py`
- 购物车服务：`backend/app/services/cart_service.py`
- Web Debug 类型：`web-debug/src/api/types.ts`
- Android 类型：`android/app/src/main/java/com/example/commerceagent/data/model/`

改商品卡片字段时，后端、Web Debug、Android 三边都要同步。

当前关键接口：

| 接口 | 说明 |
| --- | --- |
| `POST /api/chat/stream` | 聊天 SSE，返回 `message`、`trace`、`product_cards`、`done` |
| `GET /api/sessions` | 会话列表 |
| `POST /api/sessions` | 新建会话 |
| `GET /api/sessions/{id}/messages` | 加载历史消息和对应商品卡片 |
| `PUT /api/sessions/{id}` | 重命名会话 |
| `DELETE /api/sessions/{id}` | 真实删除会话、消息、推荐日志、检索日志和反馈 |
| `POST /api/upload/image` | 上传用户图片 |
| `POST /api/feedback` | 点赞/点踩 |
| `GET /api/products/{id}` | 商品详情 |
| `GET /api/cart` | 查看购物车 |
| `POST /api/cart/items` | 加入购物车 |
| `PUT /api/cart/items/{position}` | 按位置修改购物车商品数量 |
| `DELETE /api/cart/items/{position}` | 按位置删除购物车商品 |

当前 SSE `message` 事件字段：

```json
{
  "content": "最终给用户看的回答",
  "message_id": "msg_xxx",
  "session_id": "sess_xxx",
  "memory": {},
  "feedback_enabled": true
}
```

Android 模拟器访问本机后端必须使用 `http://10.0.2.2:8000`，不要写 `127.0.0.1:8000`。

## 修改后检查

```powershell
.\scripts\check_project.cmd
```

也可以直接运行：

```powershell
cd backend
.\.venv\Scripts\python.exe -m pytest app\tests -q

cd ..\android
.\gradlew.bat :app:assembleDebug
```

检查通过后再提交。不要把 `backend/.env`、`models/`、`backend/app/data/chroma/`、`backend/app/data/commerce.db` 提交上去。
