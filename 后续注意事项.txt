后续注意事项

一、Doubao 技术选型切换

1. 文本大模型
   - 正式技术选型：Doubao-Seed-2.0-lite
   - 接口方式：火山方舟 OpenAI-compatible Chat Completions
   - 配置项：
     LLM_PROVIDER=doubao
     DOUBAO_API_KEY=你的火山方舟 API Key
     DOUBAO_BASE_URL=https://ark.cn-beijing.volces.com/api/v3
     DOUBAO_MODEL=doubao-seed-2-0-lite-260215

2. 文本/图片 Embedding
   - 正式技术选型：Doubao-embedding-vision
   - 接口文件：backend/app/embeddings/doubao_embedding_vision.py
   - 配置项：
     EMBEDDING_PROVIDER=doubao
     TEXT_EMBEDDING_PROVIDER=doubao
     IMAGE_EMBEDDING_PROVIDER=doubao
     DOUBAO_EMBEDDING_API_KEY=你的火山方舟或向量服务 Key
     DOUBAO_EMBEDDING_MODEL=doubao-embedding-vision-250615
     DOUBAO_EMBEDDING_DIMENSION=2048
     DOUBAO_EMBEDDING_ENABLE_REAL=true

3. 图片输入提醒
   - Doubao 多模态向量接口更适合公网图片 URL 或 TOS 地址。
   - 当前本地商品图和上传图如果不能被云端访问，真实 Doubao 图像向量可能无法直接处理。
   - 后续应补对象存储/TOS 或公网静态图片地址，再把图搜完全切到真实 Doubao。
